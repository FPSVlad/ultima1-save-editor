# Редактор сохранений Ultima 1

Редактор файлов сохранений **Ultima I: The First Age of Darkness** (DOS, 1987).
Правит и создаёт файлы персонажей (`player1.u1` ... `player4.u1`, по 820 байт)
в дружелюбном интерфейсе — без гекс-редактора.

В комплекте **консольная** и **графическая** версии. Консольная двуязычная
(русский и английский — выбор при запуске или флагом `--en` / `--ru`).

## Возможности

- Правка характеристик: хиты, сила, ловкость, стамина, харизма, мудрость,
  интеллект, монеты, опыт, еда
- Уровень в игре вычисляется из опыта (1000 XP = 1 уровень, максимум 10-й),
  так что опыт 9999 = 10-й уровень
- Правка инвентаря: самоцветы, оружие, броня, заклинания (с зарядами),
  транспорт (конь, телега, плот, фрегат, аэрокар, шаттл, машина времени)
- Переименование персонажа (только латиница — DOS-версия другое не понимает)
- Создание нового персонажа с нуля (корректно проставляет все служебные
  маркеры 0xFFFF)
- **Счётчик сбитых кораблей в космосе** (Space Ace) — нужен, чтобы принцесса
  открыла местоположение машины времени. Это поле нигде не задокументировано;
  его адрес найден экспериментально и включён в редактор как именованное поле
- Автоматический бэкап `.bak` перед каждым сохранением
- Безопасные пределы значений (хиты/деньги/еда до 9999, статы до 99) —
  опечаткой файл не испортить

## Использование

### Консольная версия
```
python ultima1_editor.py [путь\к\player1.u1]
```
Без аргумента спросит путь к файлу.

### Графическая версия
```
python ultima1_editor_gui.py        # русский интерфейс
python ultima1_editor_gui_en.py     # английский интерфейс
```

### Сборка standalone exe (Windows)
```
pip install pyinstaller
pyinstaller --onefile --windowed ultima1_editor_gui.py
```
Готовый exe появится в папке `dist\`. На целевой машине Python не нужен.

## Важно

- **Закрой DOSBox перед правкой** — запущенная игра при выходе перезапишет
  файл своим состоянием из памяти.
- Сохраняй игру командой `Q` на глобальной карте перед правкой.
- В версии GOG изменённые файлы могут лежать в `<папка игры>\cloud_saves\`.
- Не задирай интеллект выше ~200: цены в магазинах считаются от INT и
  взлетят до неприличия.
- Не правь байты в средней части файла (маркеры `0x54`–`0x96`, карта
  объектов `0xB4`+) без нужды: маркеры `0xFFFF` завершают списки инвентаря,
  а карта объектов спавнит существ.

## Формат файла сохранения (820 байт)

По данным [ModdingWiki: Ultima I Save Game Format](https://moddingwiki.shikadi.net/wiki/Ultima_I_Save_Game_Format)
с нашим экспериментальным находкой счётчика космических побед. Все 16-битные
значения — little-endian.

| Смещение | Размер | Поле |
|----------|--------|------|
| 0x00 | 15 | Имя персонажа (ASCII + нулевые) |
| 0x10 | 2 | Раса (0 человек, 1 эльф, 2 дворф, 3 боббит) |
| 0x12 | 2 | Класс (0 воин, 1 клирик, 2 маг, 3 вор) |
| 0x14 | 2 | Пол (0 муж., 1 жен.) |
| 0x16 | 2 | Хиты (Hit Points) |
| 0x18 | 2 | Сила |
| 0x1A | 2 | Ловкость |
| 0x1C | 2 | Стамина |
| 0x1E | 2 | Харизма |
| 0x20 | 2 | Мудрость |
| 0x22 | 2 | Интеллект |
| 0x24 | 2 | Монеты |
| 0x26 | 2 | Опыт (1000 на уровень, максимум 9999) |
| 0x28 | 2 | Еда |
| 0x2A | 2 | Оружие в руках |
| 0x2C | 2 | Готовое заклинание |
| 0x2E | 2 | Броня на теле |
| 0x30 | 2 | Транспорт в ожидании |
| 0x34 | 2 | X координата |
| 0x36 | 2 | Y координата |
| 0x4C–0x52 | 2 каждое | Самоцветы: красный, зелёный, синий, белый |
| 0x54 | 2 | Маркер 0xFFFF (конец списка брони) |
| 0x56–0x5E | 2 каждое | Броня в рюкзаке: кожаная, кольчуга, латы, вакуумный, отражающий |
| 0x60 | 2 | Маркер 0xFFFF (конец списка оружия) |
| 0x62–0x7E | 2 каждое | Оружие в рюкзаке (кинжал ... бластер) |
| 0x80 | 2 | Маркер 0xFFFF (конец списка заклинаний) |
| 0x82–0x94 | 2 каждое | Заряды заклинаний (Open ... Kill) |
| 0x96 | 2 | Маркер 0xFFFF (конец списка транспорта) |
| 0x98–0xA4 | 2 каждое | Транспорт: конь, телега, плот, фрегат, аэрокар, шаттл, машина времени |
| **0xA6** | **2** | **Сбито вражеских кораблей в космосе (Space Ace)** — наша экспериментальная находка, нигде не задокументирована |
| 0xA8 | 2 | Маркер 0xFFFF |
| 0xAC | 2 | Пройдено шагов |
| 0xB4 | 80 | Карта объектов (существа/транспорт на карте мира) |

## Файлы проекта

- `ultima1_editor.py` — двуязычный консольный редактор
- `ultima1_editor_gui.py` — GUI (русский)
- `ultima1_editor_gui_en.py` — GUI (английский)
- `ultima1_diff.py` — дифф-инструмент: сравнивает два сохранения и показывает
  изменённые поля (пригодится для поиска неизвестных полей)

## Как нашли поле 0xA6

1. Сохрани игру (`Q` на глобальной карте), скопируй `player1.u1` в `before.u1`.
2. Сбей в космосе ровно один корабль, вернись шаттлом, сохрани снова.
3. Запусти `python ultima1_diff.py before.u1 after.u1` — поле, выросшее на 1
   в недокументированной зоне, и есть счётчик.
4. Проверено: значение 25 показывает «Enemy vessels...25» в инвентаре игры (`Z`).
